## About this fork

A reference fork of [dzlab/deepprojects](https://github.com/dzlab/deepprojects), preserving upstream learning resources from July 2020. The collection covers computer vision, language modelling, recommendation, time series, and visualization.

These examples are credited to their upstream authors. Notebook dependencies and setup vary by example; the Binder badge below points to the upstream repository. Start with the [dataset index](datasets.md), [courses](courses.md), and [resources](resources.md).

The upstream [Unlicense](LICENSE.md) is preserved. External datasets and models have their own provider terms. The original upstream README follows.
